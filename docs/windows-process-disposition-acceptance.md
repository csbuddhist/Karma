# Windows 高风险画面进程处置验收

本清单用于 Windows 10/11 真机验证。只使用本地、可公开测试的合成画面；不得保存真实敏感画面、OCR 原文或未加密截图。

## 准备

1. 安装并启动 `KarmaService`、交互式会话 Agent 和管理界面。
2. 启用保护，将 `recognition.immediateThreshold` 设置为测试模型可稳定命中的值。
3. 分别准备浏览器、图片查看器和视频播放器测试进程，并记录其 PID 与启动时间。

## 功能

1. 在前台浏览器显示命中画面，确认对应浏览器进程被立即关闭，其他应用保持运行。
2. 对图片查看器和视频播放器重复测试，确认只处置命中显示器上的前台来源进程。
3. 在双屏环境中让命中画面与非命中应用分别位于不同显示器，确认非命中应用不被关闭。
4. 将命中窗口快速切换到后台，确认处置仍绑定帧处理开始时记录的来源，新的前台进程不会被关闭。
5. 关闭保护或将分数降到阈值以下，确认不会触发进程处置。

## 安全与竞态

1. 在观察提交后、Service 处置前结束目标进程并复用 PID，确认新进程不会被终止。
2. 修改目标可执行路径或让创建时间不匹配，确认处置结果为身份变化而不是终止。
3. 确认 Agent 不具备直接终止进程的权限，只有通过认证的观察请求可触发 Service 处置。
4. 连续播放命中内容，确认每个显示器的五秒冷却避免重复处置队列。

## 记录

记录 Windows 版本、单屏/多屏配置、应用版本、处置结果与不含画面内容的审计事件。浏览器、图片查看器、视频播放器和 PID 复用场景全部通过后，才可标记真机验收完成。
