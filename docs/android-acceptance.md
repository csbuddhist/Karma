# Android 真机验收

本清单用于 Android 11–15 真机。`cargo test -p karma-mobile-ffi` 和 Gradle JVM 单元测试只能证明
决策逻辑与预处理算法正确，不能证明截图权限、厂商 ROM 存活、推理性能或识别准确率。每项结果附
截图、录屏或 `adb logcat` 片段作为证据；证据中不得包含被识别的画面内容。

## 准备

1. 按 [模型资产说明](model-assets.md) 导出模型到 `target/model-assets/viddexa-nano`。
2. `cd apps/karma-android && gradle assembleDebug`，确认构建日志没有 “no model” 警告。
3. 安装 APK，设置管理员密码，记录恢复码。
4. 按状态页清单依次开启：无障碍服务（必要时先“允许受限设置”）、设备管理器、不限制电池、通知、厂商自启动。
5. 启用“设置看门”。

## 设备矩阵

至少覆盖：Pixel（原生 Android 14 或 15）、小米/红米（HyperOS）、OPPO/一加（ColorOS）、vivo（OriginOS）、
华为或荣耀（Android 内核机型）、三星（One UI）各一台。记录型号、系统版本、SoC。

## 功能验证

- [ ] 重启手机后，首次解锁 30 秒内状态页显示“保护已开启”，常驻通知出现。
- [ ] 在浏览器中打开测试图集：高风险图片在 1.5 秒内被关闭（回到桌面并显示遮罩），遮罩显示原因和冷却倒计时。
- [ ] 冷却期内重新打开该浏览器：立即被关闭，不出现内容画面。
- [ ] 冷却结束后可正常打开；“管理员解锁”输入密码后可提前打开。
- [ ] 视频应用（抖音/快手/B 站/YouTube 至少两款）播放高风险片段：按 1 fps 采样后被关闭。
- [ ] Chrome 无痕标签页：截图被拒绝后浏览器被关闭（默认策略）；管理员关闭该选项后不再关闭。
- [ ] 网址黑名单：在 Chrome、Edge、Firefox、三星浏览器和一款国产浏览器中访问被禁网站，均被关闭。
- [ ] 应用黑名单：被禁应用打开后立即被关闭，不截图。
- [ ] 时段规则：导入桌面端 `schedules`（`target: browsers`），时段内浏览器被关闭，时段外正常。
- [ ] 正常应用（微信、地图、相机、银行类 `FLAG_SECURE` 应用）连续使用 30 分钟无误关闭。
- [ ] 输入法、桌面、系统界面、拨号界面从不被截图或关闭。
- [ ] 未打包模型的 APK：状态页显示模型缺失，应用/网址/标题/时段规则仍然生效。
- [ ] 篡改 APK 内模型（长度或 SHA-256 不符）：状态页显示校验失败，不进行图像推理。

## 防篡改验证（L1）

- [ ] 设置 → 应用 → Karma：页面被立即返回并弹出密码框。
- [ ] 设置 → 无障碍 → Karma 保护：同上。
- [ ] 设置 → 设备管理器 → Karma：同上。
- [ ] 长按桌面图标 → 卸载：卸载对话框被返回；系统也因设备管理器拒绝卸载。
- [ ] 各厂商安全中心/手机管家中的 Karma 条目：被返回。
- [ ] 输入正确密码后 10 分钟内可修改；超时或重启后看门恢复。
- [ ] 5 次错误密码后锁定 30 秒；恢复码只能使用一次。
- [ ] 通过快速设置或 ADB 关闭无障碍服务后，15 分钟内收到“保护已被削弱”通知，活动日志有记录。
- [ ] “准备卸载”需要密码，完成后可以正常卸载。

## 防篡改验证（L2 设备所有者）

- [ ] 在无账号的新设备上执行 `adb shell dpm set-device-owner com.karma.android/.guard.KarmaDeviceAdminReceiver` 成功。
- [ ] 无法卸载、无法进入安全模式、无法从设置恢复出厂、无法添加用户、开发者选项与 ADB 不可用。
- [ ] 其他第三方无障碍服务无法开启。
- [ ] `Terminate` 决策挂起应用，冷却结束（含重启后）自动解除挂起。
- [ ] “准备卸载”后所有限制解除、设备所有者被移除。
- [ ] 记录哪些厂商 ROM 不支持或部分支持设备所有者。

## 存活与性能（M3）

- [ ] 各厂商机型在按引导完成设置后连续 24 小时存活（每小时打开一次测试图集验证）。
- [ ] 连续使用（浏览网页、刷短视频）1 小时的电量消耗，与关闭 Karma 时对比。
- [ ] 单帧耗时（截图 → 决策）在中端机上 ≤ 300 ms；记录 `framesScored` 计数与预期帧率一致。
- [ ] 锁屏、息屏、低电量模式下不崩溃；解锁后继续工作。

## 隐私验证

- [ ] 应用数据目录中只有封装状态文件和包装后的密钥，没有图片文件。
- [ ] 活动日志只包含时间、类型、结果、包名、动作和原因，不含标题、网址、分数。
- [ ] 抓包确认运行期间没有任何网络请求。
